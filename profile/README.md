### In focus — Qeet ID

**Authentication should be powerful without being painful.**

Qeet ID brings modern sign-in, enterprise identity standards, and granular access control into one developer-focused platform. It is also the shared identity foundation for products across Qeet Group.

`Passkeys` · `SSO` · `MFA` · `OIDC / SAML` · `RBAC / ABAC` · `SCIM`

## 🛠 How we build

A growing portfolio needs shared standards — but not identical implementations.

- **Shared foundations.** Qeet ID connects the identity experience; Qeetrix provides reusable interface building blocks.
- **The right tool for the problem.** Go for identity, Java for payments, Kotlin for people operations, and Rust + Go for observability.
- **Clear boundaries.** Independent repositories, documented APIs, and published SDKs keep products able to evolve.
- **Trust in the details.** We design around tenant isolation, least privilege, privacy, and explicit security controls.
